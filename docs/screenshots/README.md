# Képernyőképek / Screenshots

Ide kerülnek a README-ben hivatkozott képek. Pontosan ezekkel a nevekkel mentsd őket (PNG):

| Fájlnév | Mit mutasson |
|---|---|
| `main-dark.png` | Főablak sötét témában, két panel, fülekkel, a meghajtósáv a foglaltsággal |
| `xbox-iso.png` | Egy Xbox 360 ISO böngészése (a panel fejlécében a lemezkép neve, bal oldalt a fájlok) |
| `god-convert.png` | A „GoD átalakítás” párbeszédablak kitöltve |
| `amiga-adf.png` | Egy ADF vagy DMS lemezkép tartalma |
| `image-viewer.png` | A képnézegető egy fotóval |
| `settings.png` | A Beállítások ablak |

Tippek:
- Win+Shift+S → „Ablak” mód: csak a programablakot vágja ki.
- Kb. 1280×800-as ablakméret jól olvasható a GitHubon is.
- Ne legyen a képen személyes mappanév vagy jogvédett játék borítója; a fájlnevek rendben vannak.
